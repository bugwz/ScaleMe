# 1.0.0 Release Notes

## ✨ 特性
- 提供多成员、多体脂秤的测量与记录管理，支持自动归属、手动调整、删除和历史记录导入。
- 实现蓝牙 SIG 标准协议及 Xiaomi、Wolai AFU、Senssun IF2121 和 Huawei Hagrid 等隔离的协议适配；兼容性说明基于已收集的协议数据样本和验证结果，并明确区分数据样本验证与真实设备验证。
- 提供多指标长期趋势、自适应时间聚合、全屏缩放和小组件，并保留身体成分仅供趋势参考的非医疗说明。
- 支持 Apple 健康体重与体脂数据导入，以及本地配置和测量记录的导入、导出与删除。
- 提供十种界面语言、运行时语言切换、VoiceOver 与动态字体支持，并加入色觉友好的浅色和深色主题。
- 内置完整的家庭模拟模式，可在不修改真实数据的情况下体验设备、测量、记录和趋势流程。

## 🐛 问题修复
- 稳定自动与手动测量会话，限定选中设备的输入与协议回调，并支持连续测量。
- 改进 Xiaomi 历史记录传输容错，跳过无效时间戳记录而不中断整个导入。
- 修正稠密趋势图缩放、成员分页、导航返回、下拉菜单重叠和多语言动态内容等交互与展示问题。

## 📋 其他
- 采用本地优先的版本化 JSON 存储与 iOS 完全文件保护，将设备绑定密钥保留在钥匙串，并提供应用内隐私政策。
- 重构蓝牙协议、持久化、本地化和功能模块的责任边界，并完善解析、存储、趋势与多语言的自动化验证。
- 更新“观我”品牌视觉，统一应用图标、启动动画和清新健康导向的界面风格。
