# 发布前验证指南

本指南提供可重复执行的发布前检查，不记录单次审核反馈、整改进度或验证结论。每次发布应根据实际功能执行检查，并在公开仓库之外保存验证证据。

## 功能与界面

- 冷启动、切换主标签、进入设置子页并返回，检查导航、滚动、内容遮挡和状态恢复。
- 检查支持的设备尺寸、较大字号、辅助功能和支持语言；编译成功不能替代界面验证。
- 用真实蓝牙秤验证连接、稳定测量、保存和重新启动后的数据一致性。兼容性声明应与实际设备和固件验证范围一致。
- 检查手动录入、模拟模式和真实测量的数据来源标识与隔离行为。
- 检查小组件更新、记录删除、导入导出及相应的隐私提示。

## 健康信息与数据来源

- 清晰说明真实测量依赖兼容蓝牙秤，手机本身不测量体重或身体成分。
- 区分设备上报值、计算值和模拟值；缺失输入时不生成无依据的身体成分数据。
- 检查单位、计算方法、来源链接与估算说明。消费级结果用于趋势参考，不应暗示医学诊断或临床精度。
- 检查数据说明和非医疗提示在相关页面可访问，商店截图与描述不宣传未实现或未经验证的能力。
- 只使用可追溯来源的测试数据；不要手动修改数据格式版本来充当验证证据。

## 权限与隐私

1. 按 [HealthKit 验证指南](AppReviewHealthKit.md) 检查授权、撤销权限和实际同步行为。
2. 检查蓝牙与健康权限在功能需要时请求，用途说明与实际行为一致。
3. 对照实际实现核对本地存储、小组件共享、系统健康读写、用户导出以及任何网络传输。
4. 核对 [隐私政策](PrivacyPolicy.md)、应用内政策与商店隐私申报，确认公开政策链接可正常访问。
5. 在待发布的签名归档中检查主应用与扩展的隐私清单和隐私报告。
6. 检查删除、导出及异常处理流程，确认日志和演示材料不暴露个人健康数据或设备认证信息。

## 商店信息与发布材料

- 根据实际内容填写年龄分级问卷，核对健康主题与医疗信息相关选项。
- 核对商店描述、截图、支持联系方式、隐私政策链接与当前功能。
- 提供清晰的功能入口和必要的设备条件；演示材料仅包含测试数据。
- 将提交标识、审核往来、回复草稿、构建详情和验证结果保存在非公开渠道。
- 只有完成对应验证后才作完成声明，未验证的项目保留为待办。

## 验证方法

根据改动范围执行 [开发指南](Development.md) 中的编译和 smoke 检查，并完成相关真机回归。无签名构建、模拟器运行和测试夹具通过，均不能替代真实蓝牙硬件、系统授权或最终签名归档验证。

参考：[Apple 审核指南](https://developer.apple.com/app-store/review/guidelines/)、[年龄分级定义](https://developer.apple.com/help/app-store-connect/reference/app-information/age-ratings-values-and-definitions)、[隐私清单检查](https://developer.apple.com/documentation/technotes/tn3181-debugging-invalid-privacy-manifest)。
