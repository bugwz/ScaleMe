观我(ScaleMe)는 개인과 가족의 체중 및 체성분을 기록하는 네이티브 iOS 앱입니다. 호환되는 체중계에 Bluetooth로 연결하거나 측정값을 직접 입력하고, 구성원·기기·기간별로 기록과 변화 추세를 확인할 수 있습니다.

계정을 등록할 필요가 없습니다. 구성원 정보, 기기 설정 및 측정 기록은 기기에 저장되며 개발자 서버로 전송되지 않습니다. 앱 자체의 클라우드 동기화도 제공하지 않습니다. Apple 건강 읽기·쓰기와 파일 가져오기·내보내기는 사용자가 직접 활성화하거나 실행합니다.

## 주요 기능

### 측정과 기록

- 호환되는 Bluetooth 체중계를 검색하고 연결하여 측정 진행 상태와 기기가 제공하는 데이터를 표시하고 안정된 측정 결과를 저장합니다.
- 체중을 직접 입력하고 측정 날짜와 시간을 선택하며, 필요하면 기기에 표시된 체성분 값을 추가할 수 있습니다. 과거 기록도 입력할 수 있습니다.
- 측정 상세 보기, 기록의 구성원 변경 및 삭제를 지원합니다. 지원되는 프로토콜은 체중계의 과거 기록을 읽고 구성원 연결 및 중복 제거를 수행할 수 있습니다.
- 실시간 측정은 기기 내 파일에 먼저 저장된 후 정식 기록에 반영되고 활성화된 건강 공유를 실행합니다. 저장에 실패하면 미저장 상태와 재시도 기능을 표시합니다.

### 가족 구성원과 추세

- 여러 구성원 프로필과 기기를 관리하고 구성원별 기록을 따로 확인합니다.
- 홈 화면에서 건강 지표를 선택하고 순서를 정하며, 최신 값과 지표의 의미 및 적용 가능한 참고 범위를 확인합니다.
- 구성원, 기기, 기간 및 지표별로 추세를 필터링하고 그래프와 과거 기록으로 변화를 살펴봅니다.
- 소형·중형·대형 홈 화면 추세 위젯을 제공하며, 각 위젯에서 지표, 기간, 기기, 구성원 및 표시 방식을 독립적으로 설정합니다.

### 데이터 관리와 Apple 건강

- 설정과 측정 기록을 개별 또는 함께 JSON 파일로 가져오고 내보내며, 기기 내 데이터를 삭제할 수 있습니다.
- 선택적으로 Apple 건강의 체중과 체지방률을 본인 프로필로 가져오고, 조건에 맞는 새로운 측정값을 Apple 건강에 쓸 수 있습니다.
- 앱의 동기화 스위치와 시스템 권한은 별도로 관리합니다. 동기화를 꺼도 Bluetooth 측정, 수동 기록 및 추세 확인은 계속 사용할 수 있습니다.

### 인터페이스와 손쉬운 사용

- 중국어 간체·번체, 영어, 일본어, 프랑스어, 독일어, 스페인어, 포르투갈어, 러시아어 및 한국어를 지원하며, 시스템 언어를 따르거나 앱에서 선택할 수 있습니다.
- 기본 테마와 색각을 고려한 테마를 제공하고 라이트·다크 모드 및 시스템 화면 모드에 맞추기를 지원합니다.
- 측정 상태, 그래프, 메뉴 및 입력 폼에 VoiceOver를 지원하며 Dynamic Type과 동작 줄이기 설정에 대응합니다. 실제 검증 범위는 [손쉬운 사용 검증](../Accessibility.md)을 참고하세요.
- 체중계가 없어도 인터페이스를 체험할 수 있는 가족 시뮬레이션 데이터를 제공합니다. 이 모드의 기록 변경은 실제 측정 데이터에 저장되지 않으며 다음 실행 시 기본 예제 데이터로 복원됩니다.

## 기기 호환성

Bluetooth SIG 표준 체중 및 체성분 특성 분석과 여러 제조사 프로토콜의 광고 데이터 분석 또는 GATT 측정 세션을 구현했습니다. 프로토콜마다 기능과 검증 수준이 다르므로 브랜드 이름만으로 모든 모델을 사용할 수 있다고 판단할 수 없습니다.

- 기기 검색, 이름 일치 또는 프로토콜 등록이 측정 지원을 뜻하지는 않습니다.
- 샘플 데이터 테스트는 분석 동작을 검증하며, iPhone과 실제 체중계 간 전체 동작 검증을 의미하지 않습니다.
- 실시간 측정, 체성분, 기기 기록 읽기 및 인증 설정은 개별 프로토콜에 따라 달라집니다. 확인되지 않은 필드는 알려진 지표로 저장하지 않습니다.
- 형식에 맞는 선언형 통신 규칙을 로컬 JSON 파일에서 가져올 수 있습니다. 원격 주소에서 프로토콜을 다운로드하지 않습니다.

프로토콜, 현재 기능, 검증 수준 및 연구 출처는 [체중계 프로토콜 지원표](../BluetoothProtocolSupport.md), 확장 형식은 [외부 통신 규칙](../ExternalCommunicationRules.md)을 참고하세요.

## 지표와 추정값 안내

앱은 기기 원본 값과 앱 계산값을 구분합니다. 체중, 기기가 제공한 체성분, 구성원 정보로 계산한 BMI 및 조건에 따라 보완하는 체성분은 데이터 출처와 적용 범위가 서로 다릅니다.

인식된 체성분 측정 기기에서는 기기 또는 프로토콜이 제공한 지표를 우선합니다. 유효한 주 임피던스와 구성원 정보가 있고 모델 조건을 만족할 때만 누락된 체성분 값을 실험적으로 추정합니다. 일반 체중계, 수동 기록 및 Apple 건강에서 가져온 데이터에는 이 기본 보완 계산을 적용하지 않습니다. 주 임피던스가 없으면 BMI로 대체하여 누락된 체성분을 추정하지 않습니다.

계산 결과는 측정 기록과 함께 저장하며 기기 원본 값과 앱 추정값은 따로 저장합니다. 구성원 정보를 변경해도 과거 기록은 자동으로 재계산되지 않지만, 기록을 다른 구성원에게 재할당하면 재계산됩니다. 앱 추정값은 Apple 건강에 쓰지 않습니다. 모델의 연령 범위, 기기 적용 가정 및 경험 규칙에는 한계가 있으며, 앱 추정값은 제조사 공식 알고리즘이나 임상 측정으로 간주할 수 없습니다.

앱의 데이터 설명과 각 지표 계산 페이지에서 공식, 출처 및 적용 범위를 확인할 수 있습니다. 기술적 내용은 [데이터·동기화·개인정보](../DataAndPrivacy.md)를 참고하세요. 체성분 결과는 추세 관찰용이며 진단, 치료 또는 의료적 판단에 사용하지 않습니다.

## 데이터 저장과 개인정보

### 기기 내 저장

구성원 정보, 기기 설정 및 측정 기록은 버전이 지정된 JSON 파일로 앱 샌드박스에 저장합니다. 설정과 기록은 따로 저장하며 iOS Complete File Protection을 적용합니다. 기기 연결 및 인증 비밀 정보는 시스템 Keychain에 저장합니다.

홈 화면 위젯은 기기 내 App Group을 통해 간결한 추세 스냅샷을 읽습니다. 스냅샷은 AES-GCM으로 암호화하며 키는 공유 Keychain에서 관리합니다. 이는 같은 기기 안에서 앱과 확장 프로그램 사이에 이루어지는 데이터 공유입니다.

앱에는 계정 시스템, 광고 또는 분석 데이터 전송 서비스가 없습니다. 구성원 정보와 건강 측정값을 개발자 서버로 전송하지 않으며 iCloud로 이 데이터를 실시간 동기화하지 않습니다.

### 사용자가 관리하는 데이터 이동

- **시스템 백업**: 설정과 측정 파일은 사용자가 활성화한 기기 시스템 백업에 포함될 수 있습니다. 백업과 복원은 시스템이 담당합니다.
- **Apple 건강**: 읽기·쓰기는 기본적으로 꺼져 있으며 사용자 설정과 권한 허용이 필요합니다. 읽은 데이터는 본인 프로필로만 가져오며, 쓰기는 선택한 실제 기기에서 생성된 본인의 새로운 안정 측정값으로 한정합니다. 가져온 과거 기록, 수동 기록, 시뮬레이션 데이터 및 앱 추정값은 Apple 건강에 쓰지 않습니다. 동기화를 꺼도 이미 쓰거나 가져온 데이터는 삭제되지 않습니다.
- **파일 가져오기·내보내기**: 사용자가 직접 실행합니다. 내보낸 JSON은 암호화되지 않은 일반 텍스트이며 구성원 정보, 기기 정보 및 측정 기록을 포함할 수 있습니다. 저장 위치와 공유 대상은 사용자가 선택합니다.
- **진단 내보내기**: 사용자가 직접 수집하고 내보내며 기기 식별자와 측정 페이로드가 포함될 수 있습니다. 원본 파일을 공개적으로 공유하지 않아야 합니다.

전체 내용은 [개인정보 처리방침](../PrivacyPolicy.md), 건강 권한과 검증 절차는 [HealthKit 검증 가이드](../AppReviewHealthKit.md)를 참고하세요.

## 기술과 프로젝트 구조

최소 iOS 17을 지원하며 Swift, SwiftUI, Charts, CoreBluetooth, HealthKit, WidgetKit 및 CryptoKit을 사용합니다. 인터페이스, 도메인 계산, 프로토콜 분석 및 시스템 서비스는 책임에 따라 분리합니다.

```text
ScaleMe/
├── App/              # 앱 진입점, 탐색, 시작 흐름 및 전역 상태
├── Core/             # 현지화 등 기능 공통 기반
├── Domain/           # 도메인 모델, 계산 및 추세 분석
├── Infrastructure/   # Bluetooth, 영구 저장, 건강 데이터, 진단 및 위젯 내보내기
├── Features/         # 홈, 측정, 추세, 기기 및 설정
├── Shared/           # 디자인 시스템과 공유 컴포넌트
└── Resources/        # Assets, String Catalog 및 설정 리소스
ScaleMeWidget/        # 홈 화면 추세 위젯
ScaleMeWidgetShared/  # 앱과 위젯이 공유하는 데이터 규약과 저장
Docs/                # 구현 및 검증 문서
└── readme/           # README 전체 번역
Tests/Smoke/         # 프로토콜, 도메인 계산 및 현지화 등의 결정적 검사
Tools/               # 개발 및 리소스 생성 도구
```

계층, 상태 전환 및 Bluetooth 처리 흐름은 [아키텍처와 구현](../Architecture.md)을 참고하세요.

## 프로젝트 실행

1. Xcode 26 이상에서 `ScaleMe.xcodeproj`를 열고 `ScaleMe` scheme을 선택합니다.
2. 시뮬레이터에서 실행하고 설정 → 데이터 관리에서 시뮬레이션 데이터를 활성화하여 구성원, 기기, 기록 및 그래프를 체험합니다.
3. 실제 Bluetooth 측정을 테스트하려면 개발 팀을 설정하고 iPhone에 설치한 뒤 기기 검색 시 Bluetooth 권한을 허용합니다.
4. 위젯을 테스트하려면 앱과 `ScaleMeWidget` 확장 프로그램에 서로 맞는 App Groups 및 Keychain Sharing 기능을 설정합니다.

시뮬레이터와 자동 테스트는 Bluetooth, HealthKit 및 개별 체중계 모델의 실제 기기 검증을 대신할 수 없습니다. 환경 요구 사항, 빌드 명령 및 테스트 진입점은 [개발과 검증](../Development.md)을 참고하세요.
