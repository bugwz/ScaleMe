观我（ScaleMe）は、個人と家族の体重・体組成を記録するネイティブ iOS アプリです。互換性のある体重計に Bluetooth で接続するほか、測定値を手入力でき、メンバー・機器・期間ごとに履歴と変化を確認できます。

アカウント登録は不要です。メンバー情報、機器設定、測定記録は端末内に保存され、開発者のサーバーへ送信されません。アプリ独自のクラウド同期もありません。Apple ヘルスケアの読み書きやファイルのインポート・エクスポートは、ユーザーが有効化または操作します。

## 主な機能

### 測定と記録

- 互換性のある Bluetooth 体重計を検出・関連付けし、測定の進行状況と機器から得られるデータを表示して、安定した測定結果を保存します。
- 体重を手入力し、測定日時を選択できます。必要に応じて機器に表示された体組成値を追加し、過去の記録も入力できます。
- 測定の詳細表示、所属メンバーの変更、記録の削除に対応します。対応プロトコルでは秤内の履歴を取得し、メンバーの照合と重複除去を行えます。
- リアルタイム測定は端末内のファイルへ保存した後、正式な記録となり、有効なヘルスケア共有を実行します。保存に失敗すると未保存状態と再試行の操作を表示します。

### 家族のメンバーと推移

- 複数のメンバープロフィールと機器を管理し、各メンバーの記録を個別に確認できます。
- ホームの健康指標を選択・並べ替えし、最新値、指標の意味、適用可能な参考範囲を確認できます。
- メンバー、機器、期間、指標で推移を絞り込み、グラフと履歴から変化を確認できます。
- 小・中・大サイズのホーム画面ウィジェットを提供し、それぞれ指標、期間、機器、メンバー、表示方法を独立して設定できます。

### データ管理と Apple ヘルスケア

- 設定と測定記録を個別または一括で JSON ファイルにインポート・エクスポートでき、端末内データの削除も可能です。
- 任意で Apple ヘルスケアの体重・体脂肪率を本人のプロフィールに取り込み、条件を満たす新しい測定を書き込めます。
- アプリの同期スイッチとシステムの許可は別々に管理します。同期を無効にしても、Bluetooth 測定、手入力、推移の確認は利用できます。

### インターフェースとアクセシビリティ

- 簡体字中国語、繁体字中国語、英語、日本語、フランス語、ドイツ語、スペイン語、ポルトガル語、ロシア語、韓国語に対応し、システム設定への追従またはアプリ内での選択が可能です。
- 標準テーマと色覚に配慮したテーマがあり、ライト・ダーク表示およびシステム外観への追従に対応します。
- 測定状態、グラフ、メニュー、フォームに VoiceOver を提供し、Dynamic Type と「視差効果を減らす」設定にも対応します。実際の検証範囲は[アクセシビリティ検証](../Accessibility.md)を参照してください。
- 体重計がなくても画面を体験できる家族のサンプルデータを提供します。シミュレーション中の記録変更は正式な測定データに書き込まれず、次回起動時にプリセットへ戻ります。

## 機器の互換性

Bluetooth SIG 標準の体重・体組成特性の解析、および複数メーカーのプロトコルのアドバタイズ解析や GATT 測定セッションを実装しています。機能と検証状況はプロトコルごとに異なるため、ブランド名だけで全モデルが使用可能とは判断できません。

- 機器の検出、名前の一致、プロトコルの登録は、測定対応を意味しません。
- サンプルデータのテストは解析動作を検証するもので、iPhone と実際の体重計による一連の動作検証とは異なります。
- リアルタイム測定、体組成、秤内履歴の取得、認証設定は個別のプロトコルに依存します。未確認のフィールドを既知の指標として保存しません。
- 規定の形式に合う宣言的通信ルールをローカル JSON ファイルから取り込めます。リモート URL からプロトコルをダウンロードしません。

プロトコル、現在の機能、検証段階、調査元は[体重計プロトコル対応表](../BluetoothProtocolSupport.md)、拡張形式は[外部通信ルール](../ExternalCommunicationRules.md)を参照してください。

## 指標と推定値について

機器の元の値とアプリの計算値は区別されます。体重、機器提供の体組成、プロフィールから計算する BMI、条件に応じて補う体組成では、データの由来と適用範囲が異なります。

認識された体組成計では機器またはプロトコルの指標を優先します。有効な主インピーダンスとプロフィール情報があり、モデルの条件を満たす場合に限り、不足する体組成を実験的に推定します。通常の体重計、手入力、Apple ヘルスケアからの取り込みでは、この既定の補完を行いません。主インピーダンスがない場合、BMI を代用して不足する体組成を推定しません。

計算結果は測定記録とともに保存し、機器の元の値とアプリ推定値を分けて保持します。プロフィールの変更で過去の記録は自動再計算されませんが、記録の所属メンバーを変更すると再計算されます。アプリ推定値はヘルスケアに書き込みません。年齢範囲、機器への適用仮定、経験則には制限があり、メーカー公式の計算方法や臨床測定と同一視できません。

アプリ内の「データ説明」と各指標の計算ページには、式、出典、適用範囲があります。技術的な詳細は[データ・同期・プライバシー](../DataAndPrivacy.md)を参照してください。体組成の結果は変化を観察する参考情報であり、診断、治療、医療上の判断には使用できません。

## データ保存とプライバシー

### 端末内保存

メンバー情報、機器設定、測定記録は、バージョン管理された JSON ファイルとしてアプリのサンドボックスに保存します。設定と記録は別ファイルで、iOS Complete File Protection を適用します。機器の紐付け・認証の秘密情報はシステムの Keychain に保存します。

ホーム画面ウィジェットは端末内の App Group から簡潔な推移スナップショットを読み取ります。スナップショットは AES-GCM で暗号化し、鍵は共有 Keychain で管理します。同じ端末内のアプリと拡張機能の間で行うデータ共有です。

アカウントシステム、広告、分析データの送信サービスは含まれません。メンバー情報と健康測定を開発者サーバーへ送らず、これらを iCloud でリアルタイム同期しません。

### ユーザーが管理するデータの移動

- **システムバックアップ**：設定と測定ファイルは、ユーザーが有効化した端末のシステムバックアップに含まれる場合があります。バックアップと復元はシステムが担当します。
- **Apple ヘルスケア**：読み書きは初期状態で無効で、設定と許可が必要です。読み取り先は本人のプロフィールのみで、書き込みは選択した実機による本人の新しい安定測定に限ります。履歴の取り込み、手入力、サンプルデータ、アプリ推定値は書き込みません。同期を無効にしても、書き込み済み・取り込み済みのデータは削除されません。
- **ファイルのインポート・エクスポート**：ユーザーの操作で実行します。エクスポートした JSON は暗号化されていない平文で、メンバー情報、機器情報、測定記録を含む場合があります。保存先と共有相手はユーザーが選びます。
- **診断情報のエクスポート**：ユーザーが収集・出力します。機器識別子や測定ペイロードを含む場合があるため、元のファイルを公開すべきではありません。

詳細は[プライバシーポリシー](../PrivacyPolicy.md)、ヘルスケアの許可と検証手順は[HealthKit 検証ガイド](../AppReviewHealthKit.md)を参照してください。

## 技術とプロジェクト構成

iOS 17 以降を対象に Swift、SwiftUI、Charts、CoreBluetooth、HealthKit、WidgetKit、CryptoKit を使用しています。画面、ドメイン計算、プロトコル解析、システムサービスを責務ごとに分けています。

```text
ScaleMe/
├── App/              # アプリ入口、ナビゲーション、起動処理、全体状態
├── Core/             # ローカライズなど機能横断の基盤
├── Domain/           # ドメインモデル、計算、推移分析
├── Infrastructure/   # Bluetooth、永続化、健康データ、診断、ウィジェット出力
├── Features/         # ホーム、測定、推移、機器、設定
├── Shared/           # デザインシステムと共通コンポーネント
└── Resources/        # Assets、String Catalog、設定リソース
ScaleMeWidget/        # ホーム画面の推移ウィジェット
ScaleMeWidgetShared/  # アプリとウィジェット共通のデータ定義と保存
Docs/                # 実装と検証のドキュメント
└── readme/           # README の各言語への全文翻訳
Tests/Smoke/         # プロトコル、計算、ローカライズなどの決定的な検査
Tools/               # 開発とリソース生成のツール
```

階層、状態遷移、Bluetooth の処理経路は[アーキテクチャと実装](../Architecture.md)を参照してください。

## 実行方法

1. Xcode 26 以降で `ScaleMe.xcodeproj` を開き、`ScaleMe` scheme を選びます。
2. シミュレータで実行し、「設定 → データ管理」でサンプルデータを有効にして、メンバー、機器、記録、グラフを試します。
3. 実際の Bluetooth 測定を試す場合は開発チームを設定して iPhone にインストールし、機器検索時に Bluetooth の使用を許可します。
4. ウィジェットのテストでは、アプリと `ScaleMeWidget` 拡張機能に対応する App Groups と Keychain Sharing を設定します。

シミュレータや自動テストは、Bluetooth、HealthKit、個別の秤モデルの実機検証の代わりにはなりません。環境要件、ビルドコマンド、テスト入口は[開発と検証](../Development.md)を参照してください。
